# Батон — Bread Empire

Однопользовательская браузерная игра на русском языке. Vanilla JavaScript, HTML и CSS; серверная логика, регистрация, внешние ресурсы и установка пакетов не требуются. Батон нарисован в SVG, звуки синтезируются Web Audio после взаимодействия.

## Запуск

Из каталога репозитория:

```sh
npm start
```

Или `python3 -m http.server 3000 --bind 0.0.0.0`. Откройте адрес сервера в браузере. Для публикации скопируйте `index.html`, `style.css`, `game.js`, `economy.js`, `save.js` на любой статический хостинг. Нужен HTTP-сервер: ES-модули не следует открывать через `file://`.

## Игровые системы

- Семь производителей, девять улучшений, геометрический рост цен и покупки ×1 / ×10 / ×100 / MAX с суммированием округлённых цен каждого экземпляра.
- Комбо (отдельно от производства), критические клики, золотой батон с четырьмя наградами. События каждые 45–90 секунд, доступны 7 секунд. После 10 000 заработанных крошек появляются хлебный дождь с собираемыми крошками, безумная печь, гигантский батон на пять ударов и праздник хлеба.
- Восемь постоянных достижений (+2% производства каждое), перерождение от миллиона крошек текущего цикла, золотые корочки и три постоянных улучшения. +10% за каждую заработанную корочку сохраняется после её траты.
- Семь косметических скинов; открытая коллекция сохраняется при перерождении.
- Автосохранение каждые 10 секунд, при скрытии и уходе со страницы. Офлайн-доход 25% (до 100% с улучшением) за максимум четыре часа. В скрытой вкладке действует офлайн-ставка; временные усиления не увеличивают офлайн-доход.
- Экспорт и проверяемый импорт JSON версии 1, двукратное подтверждение полного сброса. Импорт заменяет игру только после валидации и подтверждения. При недоступном localStorage игра продолжает работать, доступен экспорт.
- Мобильные вкладки, клавиатурное управление кнопками, настройка звуков и громкости, сокращённые/полные числа, режим уменьшенных анимаций и системный prefers-reduced-motion.

## Проверки

Node.js 22+:

```sh
npm test
```

Тесты проверяют стартовую экономику, все режимы мультипокупки, недостаток денег, независимость множителей, обновление бонусов, сброс при перерождении, ограничения офлайн-дохода, сохранение/восстановление, некорректные данные и числовые пределы.

Для ручной проверки: сделайте 30 кликов, купите мышь и проверьте прирост баланса; перезагрузите страницу. В настройках экспортируйте сохранение, импортируйте его обратно, затем попробуйте повреждённый JSON. Проверьте мобильные вкладки на ширине 320 px и управление Tab / Enter / Space. Временные бонусы одного типа обновляют срок, а не перемножают эффект.

## Структура

`economy.js` — чистые расчёты и изменения состояния; `save.js` — валидация и localStorage; `game.js` — ввод, игровой таймер, интерфейс, аудио и события. Доход считается по реальному прошедшему времени с разбиением на момент истечения бонусов. Числа ограничены 1e100, производители — 10 000 каждого типа; это технические пределы для защиты от переполнения. Частицы, уведомления и объекты событий ограничены и удаляются после завершения.

Прогресс хранится в браузере для конкретного адреса сайта. Для переноса между устройствами или адресами используйте экспорт. Баланс поздних стадий требует дальнейшего игрового тестирования.
